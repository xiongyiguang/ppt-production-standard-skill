# imagegen版式研究与PowerPoint原生重构

适用于重点内容页新建、业务关系表达优化，以及用户要求借鉴生成参考图的构图、主体比例或配色。由当前PPT制作任务执行，局部任务只处理授权页面。生成图负责探索页面设计，正式稿默认使用原生对象落实已确认内容和关系。

## 选择交付方式

| 用户需要 | 执行方式 | 交付边界 |
|---|---|---|
| 优化页面、借鉴参考构图，或需要文字与节点可编辑 | 本指南：版式研究与原生重构 | 原生文字、容器、连接器和所需矢量对象；独立照片或插图按素材属性说明 |
| 明确要求把主体文字或结构生成图片、“给图自行回填” | [主体图片替换](imagegen-content-replacement.md) | 独立位图或已授权的图片回填，说明内部文字不可逐项编辑 |
| 仅补充局部插画或图标，已有结构保持 | [局部视觉润色](local-visual-polish.md) | 在原生页面中放置独立素材，不自动改为整页位图 |

“参考图很好”“照这个布局画下来”默认承接当前PPT的可编辑目标；明确要求交付图片时按图片模式。已有授权和偏好足够时直接实施，只有交付方式确实冲突或缺失且影响结果时才确认。纯改字不触发版式生图，用户禁止生图时按要求直接原生制作。

## 核对内容与当前文件

读取最新保存稿及授权页的文字、备注、对象和实际画面，记录输入版本或哈希。已有渲染与当前哈希相符时可作对照；不把旧渲染当成用户最新修改稿，不触碰未保存的工作。

按[内容设计](content-led-design.md)说明主要关系、当前表达问题、必须保留的字段、否定词、边界及例外。表格适合逐项比较或核对时保留；只有关系确被行列掩盖或用户明确要求改版时，才重构主体。原版、生成研究稿与原生稿的内容基线应相同，不能靠删细节或增加未经证实的功能制造视觉改善。

## 生成完整的构图参考

加载当前可用imagegen技能并实际生成，通常先研究一份；已有符合本轮方向的研究图可直接复用。存在具体缺陷再定向迭代，不为凑方案数量反复生成。

提示词包括本页核心判断、完整展示内容、主要关系、实际画布比例、当前品牌主色及辅助色、二维风格、正文层级、主体占比与阅读路径。可以在研究图中生成标题和说明以观察版式，正式文字仍从已确认内容原生制作；生成文字不能成为业务事实的新来源。

重点研究：

- 主体各区域的大小、比例、位置和留白，主要对象是否得到足够面积。
- 问题与响应、输入与输出、内外边界、阶段或层级如何被直接看懂。
- 主色、浅色底、辅助色分别承担标题、分组、边界或结果强调中的什么作用。
- 名称与说明、大编号与正文、对象图标与关系线之间的视觉层级。

传入已确认的最小内容摘录和获准素材，研究稿可用匿名对象；不把客户完整文件、真实界面、凭据或无关资料作为装饰输入。没有可用工具或生成失败时继续完成可执行的原生工作，准确标注研究项状态。

## 选择可借鉴的设计

查看成图，再形成简短的采纳记录，不以“专业、美观”代替判断：

| 参考图中的元素 | 采纳原则 |
|---|---|
| 主体构图、区域占比、大小与位置 | 关系准确且可读时充分保留；用户已认可的布局不为制造差异而另起结构 |
| 色彩分区、浅色底和边界强调 | 保留其表达作用，映射到当前模板的主题槽位及深浅变化；不把某项目蓝绿分工推广到其他品牌 |
| 帮助识别数据源、资料、模型、阶段或问题的图标 | 保留这种识别作用，采用合适的原生或授权矢量图标；按真实对象选用 |
| 标题、模块名与补充说明 | 采用其主次关系，以准确文字原生重建，适配模板和字号规范 |
| 无依据的组件、动作、接口承诺、数据或错误箭头 | 删除或纠正，不从研究图补造业务范围 |
| 无助理解的装饰、重复实色框、光晕或过密小图标 | 去除或减轻，保持有效信息和主要对象的识别能力 |

“少图标”指控制装饰和重复，不能自动解释为不使用图标。用户明确认可参考图的语义图标后，应保留对应识别方式。也不能只添图标或删表格边线就声称已改善关系。

## 将构图落实为原生页面

先按参考确定主体区域的占比、内容位置及关系线，再放入原生文字和必要图标。检查原生稿是否保留了参考图的第一视觉重点、主体大小、阅读顺序和配色作用；不退回旧脚本的行列布局，也不把已认可的图标、边界和浅色分区全部抽掉。

- 从当前权威模板或用户最新稿保持品牌骨架；标题、Logo、母版、版式、主题和固定装饰按授权范围保护。
- 标题、正文、节点、标签、条件和关键关系用PowerPoint原生对象。容器文字直接写入所属形状；独立标签与关系注释按语义放置，避免重叠的重复文字。
- 名称突出，解释弱化，普通正文14磅；单行1.0、多行1.2倍，段前后0。以PowerPoint实际折行判定，不依赖字符串中的换行符；空间不足时调整容器或构图。
- 通用图标优先使用现有获准素材或矢量图标库，记录名称、来源和许可。需要且工具支持时，将SVG路径转换成原生自定义几何，使用主题槽位着色并检查路径完整；不要求每次重新生成简单图标，也不把整页SVG当原生页面。
- 统一图标的笔画、视觉尺寸及配色；按对象独立组合，保持图标、名称、说明之间的编辑层级。不把图标内部可编辑与普通图片可移动混为一谈。
- 连接器沿用开放式箭头及当前规范的主题色和线条母样。数字、方向、边界和复核条件不烘焙进位图；照片、真实界面和复杂插画仍按原素材方式使用。

局部改版按最小影响范围合成：保护其他页、媒体、关系和备注，不从旧生成脚本重建整稿。纯视觉调整保留讲稿；业务表述同时改变时只同步相关讲稿。选择能保留输入结构的编辑或合成方式，不能为了字节相同而损坏关系，也不能只改页内容便宣称未影响其余部分。

## 对照检查与交付

设计与技术两条检查分别完成：

1. 同时查看原版、生成参考与原生稿：确认关系、主体比例、图标识别、颜色作用和阅读路径改善，原生实现保留有效设计。
2. 按实际安装环境用PowerPoint打开独立测试副本，检查修复提示、自动折行、行距、溢出、遮挡和连接关系。分别在100%和50%或对应实际阅读尺寸复核；查到缺陷后修正并重新渲染受影响页，干净首稿无需无意义的改动循环。
3. 对修改页代表性文字、容器、连接器以及新增图标类型，验证编辑、移动及适用的组合/取消组合。原有标题占位符或表格限制保留并说明，不把静态“无锁”当成已操作验证。
4. 核对声明未改的页面、备注与模板部件。可逐字节比较的部件按实际结果记录；导出器引入差异时复核文字、对象、关系和几何。已有匹配版本的真实渲染且环境一致时可比较未改页画面，不凭一次局部渲染宣称全稿逐页设计验收。
5. 在项目既有逐页内容、制作计划和核验记录中同步版本、采纳/删除项、编辑范围和真实检查结果。另存可辨识版本，保留最新输入；生成研究图、中间稿和客户案例留在项目，通用技能只保留方法。

记录可复用已有表，至少能查到：页码、输入版本/哈希、核心关系、参考图、采纳的布局/比例/颜色/图标、未采纳的假设、必须保留的条件、原生实现方式、当前渲染和遗留问题。没有检查的项标为待验收，不用完整记录替代实际检查。

## 可迁移的实践

- **部署与数据边界**：外部来源、受控入口及本地边界明确分区；资料与模型按真实包含关系放置，数据库、附件、知识及模型图标帮助识别。网络、资源、访问和API条件仍按原文保留，不能从参考图推导额外承诺。
- **业务问题与建设响应**：编号和语义图标识别问题，影响贴近对应问题，再用明确方向连接具体响应；确属共同平台时可用共享响应区域承载。对应关系优先，不固定三列、三图标或统一色带。
- **多类智能处理**：机制不同的需求分别展示处理路径及复核点，真正共用的知识治理独立表达；不能为形成单一流程把不同机制混在一起。
