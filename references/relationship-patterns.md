# 12 类关系表达方法

用于已明确本页判断和内容关系、需要具体构图指导的新建或整体改版任务。每个授权正文页必须作结构判断，但不要求整读本文或每页套用一种命名方法。按下表定位相关小节；售前常见关系另见[售前关系画法](presales-relationship-layouts.md)。这里提供可变的画法，不是固定样页库。

## 选型与共用边界

| 内容关系 / 读者问题 | 方法 | 数据或语义不足时 |
|---|---|---|
| 目标由哪些支柱和基础支撑 | 战略房屋 | 用目标—举措对应表 |
| 对象在两个维度上如何定位 | 2×2 矩阵 | 用维度比较表 |
| 一个问题如何分解 | 问题树 | 用分层议题清单 |
| 哪些活动共同创造价值 | 价值链 | 用活动关系图 |
| 事情按什么条件推进 | 流程图 | 先澄清步骤与条件 |
| 总量因哪些因素变化 | 桥图／瀑布图 | 用增减明细表 |
| 市场规模与内部份额如何共同构成整体 | Mekko 市场份额图 | 用分组条形图或表格 |
| 谁在何时交付什么 | 甘特／路线图 | 用阶段与里程碑表 |
| 多个方向各有哪些行动 | 多支柱网格 | 用职责／行动清单 |
| 两个数值是否有关，第三维有多大 | 散点／气泡图 | 用对比表；定性定位用矩阵 |
| 对象逐级筛选、转化后剩多少 | 漏斗图 | 用阶段数量条形图 |
| 谁向谁汇报，或谁与谁协作 | 组织／利益相关方地图 | 先分清层级与协作语义 |

- 下表的替代表达仅是候选，采用表格仍须满足[内容设计](content-led-design.md)的表格判据。缺少数值、精确日期或定量定位依据，不等于已确认的定性顺序、分层、阶段和范围也不存在；保留这些关系、标注缺口，不自动退回“名称＋说明”表。
- 先满足内容与用户要求，再调整方向、节点数、比例和页数。不规定全稿使用比例，不凑字数、卡片数、装饰数或填充率，不强制相邻页换版式。
- 草图只表达关系，不代表坐标、固定比例或必须包含的业务字段。没有事实依据的目标、负责人、收益、时间、连线、分类和结论不得补造；缺失关键输入时标待确认或换图。
- 几何按权威模板实测内容区计算，先扣除标题、概述、来源和必要注释，再布局。字体、主题色、形状文字、箭头与验收沿用主规范；不照搬固定像素、Navy/Cyan 或第三方字号。
- 默认用原生形状内文字、连接器、原生表格或可编辑图表。形状是文字容器时直接写入形状，不用“形状＋叠加文本框”替代。只有独立轴名、图注、连接说明等使用独立文本框。
- SVG 可用于辅助图形，但不把它默认当作原生可编辑对象；采用媒体例外时说明编辑限制。图内关键文字不能随整图栅格化，除非用户明确授权。
- 颜色表示类别、状态或重点，不代替文字与线型。数量、百分比、单位、时间范围和来源紧邻图或在统一脚注中可追溯。

## 1. 战略房屋

**适用与输入**：解释目标、支撑方向、行动及基础能力之间的关系。需要已有目标与举措对应关系，不用来包装无层次的功能清单。

```text
            / 愿景或目标 \
           [关键成果与目标]
           [支柱A] [支柱B]
           [各支柱对应举措]
           [共同基础与保障]
```

**构图**：屋顶收束总目标，柱体并列呈现真正同级的支撑方向；举措贴近所属柱体，共同基础跨列放底部。屋顶宽度、柱体间距、横梁连续性共同维持房屋轮廓，避免变成五条互不相干的横框。

**变化**：没有独立“愿景”和“目标”就合并；支柱过多时按有依据的层级拆页。跨支柱举措放公共横梁，标明范围，不复制成多个不同承诺。

**实现与验收**：原生三角形、矩形及形状内文字；核对每项举措归属和基础覆盖范围。不能仅因一项放在底部就宣称它支撑所有目标。

## 2. 2×2 矩阵（BCG 为专用变体）

**适用与输入**：按两个明确维度定位对象，需要轴定义、方向、分界依据及对象位置依据。

```text
                 维度Y高
             类别Ⅱ | 类别Ⅰ
             ------+------ → 维度X高
             类别Ⅲ | 类别Ⅳ
```

**构图**：轴名与高低方向放轴端，象限解释放角落，对象标签靠近点。分界不是天然的50%；按阈值或说明的定性规则放置，轴比例与数据保持一致。

**变化**：对象密集时使用编号＋旁表或拆组，避免标签覆盖。BCG 专用变体才使用市场增长率、相对市场份额及对应象限语义；普通优先级矩阵不用套 BCG 名称。

**实现与验收**：定性矩阵用原生轴线和形状；定量定位优先可编辑散点图。没有测量依据时注明定性评估，不使用精确坐标制造精度。

## 3. 问题树

**适用与输入**：拆解问题、原因、假设或解决路径。先明确拆解类型及每层分类标准，不能混把原因、结果、行动放同一层。

```text
总问题 ─┬─ 分问题A ─┬─ 证据或子问题
        │           └─ 证据或子问题
        └─ 分问题B ─── 待验证假设
```

**构图**：根节点到叶节点形成单一阅读方向；根据页面宽高和标签长度选择向右或向下。父节点对齐其子树中心，层间距留足分支标签，连接端点附着对应节点。

**变化**：分支过深时保留总览，再展开重点子树；不为对称补空分支。共享因素确实影响多支时可作独立说明，不强行重复归类。

**实现与验收**：原生节点、直角连接器；区分事实与假设。检查分类重叠和遗漏，未经论证不贴“MECE通过”；树状结构本身不证明因果。

## 4. 价值链

**适用与输入**：呈现创造价值的活动环节及介入位置，需要活动顺序、价值贡献和支撑活动的依据。

```text
[输入活动] > [核心活动] > [交付活动] > [服务活动]
            [跨环节支撑能力与资源]
```

**构图**：主活动沿主轴连续展开，每段保留可读标题；细节放环节下方并保持归属对齐，共享支持放跨段底栏。重点环节用主题强调色，不将所有环节同等突出。

**变化**：没有先后关系的能力不用首尾箭形强行串联。环节过多时分层或拆页，换行时显式标延续关系；不强制单行或固定环节数。

**实现与验收**：原生 chevron 或矩形加连接器；区分形状自带尖端与连接器端点。核对活动创造的价值、责任边界和上下游，不将普通操作流程冒充价值链。

## 5. 流程图

**适用与输入**：说明步骤、条件、角色交接和异常处理，需要起止状态、输入输出、判断条件及必要回流。

```text
输入 → 处理 → 判断 ─通过→ 交付
          ↑     └不通过→ 补正
          └─────────────┘
```

**构图**：主路径直且易读，判断分支直接标条件，回流沿外侧走线；节点使用动作名称，交接标明传递对象。方向按内容区选择；跨角色责任确有必要时才用泳道。

**变化**：主图简化时把例外放附图并明确入口，不能删掉审批、失败或重试机制。时间不是流程的必要条件，只有已知时才附时长。

**实现与验收**：原生过程框、判断菱形和连接器；检查每个分支有去向、回流有终止条件、箭头有语义，避免线穿字和无依据闭环。

## 6. 桥图／瀑布图

**适用与输入**：解释同一口径的起点经各项增减到达终点，需要起始值、带符号的变化值、终值与单位。

```text
起点总量 → +因素A → -因素B → +因素C → 终点总量
```

**构图**：首末总量柱从统一基线起，中间变化柱浮动于前一累计值和后一累计值之间，细连接线标累计水平；标签给出符号、数值和单位。负累计值保留零轴。

**变化**：中途小计明确标总量，不再次计入增减。不能相加的百分率或不同分母数据改用表格；百分比与百分点区分。涨跌不自动等于好坏。

**实现与验收**：优先可编辑瀑布图，工具不支持时用按比例计算的原生柱形并保存数据。验算“起点＋各变化＝终点”，舍入差单独解释，不靠缩放柱高隐藏差额。

## 7. Mekko 市场份额图

**适用与输入**：同时表达细分市场规模及各市场内部构成，需要同期间、同口径的规模和份额数据。

```text
┌─市场A（窄）─┬────市场B（宽）────┐
│ 公司甲      │ 公司甲           │
├────────────┤                  │
│ 公司乙      ├──────────────────┤
│             │ 公司乙           │
└────────────┴──────────────────┘
```

**构图**：列宽＝该市场规模／总体规模；列内块高＝该对象在本列的份额。同一对象跨列同色，列名与规模放上方，小块标签移至外部或旁表。

**变化**：类别过多时按明确规则合并“其他”并保留明细；缺规模数据时不能把等宽图解释为面积贡献，可改用100%堆积条形图。

**实现与验收**：按数据计算原生矩形与形状内文字，注明不是带内嵌数据的原生图表。验证列宽总和100%、每列份额100%；面积可表示总体贡献的前提是分母口径一致。

## 8. 甘特／路线图

**适用与输入**：甘特需要任务、开始结束时间、负责人及已确认依赖；路线图可以只表达阶段目标与交付物，不伪造精确日期。

```text
任务／负责人 | 时间1  时间2  时间3
任务A        | ███████
任务B        |        ███████ ◆交付
```

**构图**：左侧任务标签与右侧时间条逐行对齐，列宽先保证名称可读；时间轴统一尺度，里程碑附日期和交付物。需要时才加依赖线、进度或风险，避免左栏挤满管理字段。

**变化**：长周期用总览＋阶段放大页；不连续时间需明确断轴。缺负责人或日期标待确认。路线图阶段宽度若不代表时长，要说明。

**实现与验收**：原生表格／形状及时间条，检查日期先后、工期口径、依赖和里程碑；计划周期与完成率使用不同标记，不把整条涂满当已完成。

## 9. 多支柱网格

**适用与输入**：多个方向下组织行动与成果，需要支柱分类、举措归属；只有行具有共同维度时才构成矩阵。

```text
             支柱A       支柱B       支柱C
维度／阶段1  举措A1      举措B1      举措C1
维度／阶段2  举措A2      不适用      举措C2
```

**构图**：列头呈现同层级方向，行若代表阶段或能力则统一标注。举措包含动作及必要交付结果；若各列是独立清单，按列阅读，不用横线暗示逐项对应。

**变化**：列数由实际方向决定；空单元格区分不适用和信息缺失，不凑满。共享举措放跨列区域并标范围；贡献汇总仅在真实数据且不重复计数时使用。

**实现与验收**：原生表格或形状内文字；检查列间边界、横向可比性、共享责任及重复举措，不默认加入财务收益字段。

## 10. 散点／气泡图

**适用与输入**：比较两个定量维度或探索关联，气泡再引入非负的第三维；需要单位、时期、数据来源及对象标识。

```text
Y ↑      ○对象B
  |  ·对象A       ◯对象C（面积表示规模）
  └────────────────────────→ X
```

**构图**：轴范围反映数据，标签避让点位；重点对象用主题强调色及文字标注。气泡按面积映射数值，半径与数值平方根成比例，并给大小图例。

**变化**：重叠时用透明度、局部放大或分面，不能为了避让无说明地移动点。对数轴需标注；负值不能直接映射面积，改编码或换图。

**实现与验收**：优先原生散点／气泡图，核对坐标、大小尺度和缺失值处理；相关性不直接写成因果，定性评分需披露评估依据。

## 11. 漏斗图

**适用与输入**：同一批对象按连续阶段筛选或转化，需要每阶段数量、统计窗口、去重口径和转化率分母。

```text
[       初始对象 N1       ]
  [    有效对象 N2     ]  N2/N1
     [  成交 N3   ]       N3/N2
```

**构图**：顺序清晰，数量和阶段名称可读；旁边区分相邻转化率与整体转化率。若宽度仅示意层级，明确“不按数量比例”；定量比较优先等高、宽度按数量的条形。

**变化**：阶段数按业务决定。数量回升、重复流入或跨期对象混杂时，先解释来源，必要时改为流程加数量表，不能强画逐层收窄。

**实现与验收**：原生形状或可编辑图表；核对各率分母、失去的对象和终点数量。定量梯形需定义宽度／面积编码，避免凭视觉猜比例。

## 12. 组织／利益相关方地图

**适用与输入**：先区分汇报层级与协作网络。组织图需要正式上下级关系；利益相关方图需要主体、角色及关系类型，两者不能混为一个放射图。

```text
组织层级：        负责人
                 ├─ 团队A
                 └─ 团队B
协作网络：  主体A ─交付／审批→ 主体B
                         ↔ 核心事项 ↔ 主体C
```

**构图**：组织图按层级对齐，同级并列；利益相关方图按关系或内外部分组，核心对象可居中但不暗示管理权。线型区分汇报、协作、审批，方向与旁注一致。

**变化**：矩阵管理用实线／虚线并配图例；人员多时按组织展开。未知姓名用已知角色，不编造负责人；未经确认不赋予批准权。

**实现与验收**：原生节点和连接器；检查层级、权责、双向关系及交叉线，节点靠近或更大不能代替关系说明。

## 制作后复核

除主技能的结构、编辑性与 PowerPoint 渲染验收外，检查：图表达的关系是否来自材料；比例、方向、累计和分母是否正确；重要条件是否可见；读者能否从图中读出本页判断。无法通过时修关系或换表达，不只换颜色。
