# PPT主体内容的 imagegen 配图替换

## 适用范围与授权

用于用户明确要求将PPT主体内容、表格或结构图生成图片，或同一任务中继续发送截图要求按既定方式制图。读取当前截图及最新用户修改稿，保留用户的删减、限定条件、顺序与业务关系；不得从旧脚本恢复旧内容。

- “给图片，我自己回填”：只交付图片，不修改PPT。
- 明确授权回填：另存版本，仅改指定区域并检查回填页。
- 要求文字、节点可逐项编辑，或只是认可参考构图并要求“照这个布局画下来”：使用[版式研究与原生重构](imagegen-layout-reconstruction.md)，不能把位图宣称为可编辑PPT。
- 普通局部辅助插画使用 [local-visual-polish](local-visual-polish.md)，不自动把整块正文转成位图。
- 实际生成与编辑加载可用的 `imagegen` 技能，遵循其工具与后处理边界；本参考不授权绕过图像工具限制。

## 1. 生成前锁定规格

每张图先明确以下内容，已从对话或截图确定的事项不重复询问：

| 项目 | 必须明确 |
|---|---|
| 范围 | 仅红框/主体区，还是含标题、页脚；不把框外内容擅自重复进图 |
| 内容 | 准确文字、限定条件、对象对应及箭头方向；不得补造数字、承诺或动作权限 |
| 尺寸 | 目标宽、高、宽高比，要求是精确像素还是适配比例 |
| 品牌 | 从 [完整规范第8.4A节](ppt-production-standard.md) 取主色、对比色及使用规则，单处维护 |
| 层级 | 主标题、分组标签、正文的相对大小与字重；正文常规字重，不能全篇粗体 |
| 对齐 | 延续用户已确定的局部居中或其他要求，同层级一致 |
| 图标 | 保留帮助识别对象或理解关系的语义图标，减少无意义装饰；明确数量、删减与用户最新纠正优先 |
| 风格 | 默认简洁平面2D，避免3D、拟物、厚阴影与无意义装饰 |
| 角型 | 外框和内部卡片、标题条、内容底框、标签、流程节点默认直角矩形；圆角只因明确表达需要或用户指定而少量使用 |
| 交付 | 独立图片或授权回填，唯一最终文件及输出位置 |

替换主体的图片通常用干净的不透明白底，不能把透明抠图要求从图标流程机械带入；只有用户需要时才使用透明背景。

## 2. 按内容关系选版式

并列比较可用对照表或并列区域；递进用阶段流程；依赖用分层结构；跨角色交接用泳道；关联用节点关系图。结构服从业务含义，不为变化强行加箭头或把并列事项画成先后步骤。

检查与相邻页面的重复度。多样化不等于每页换装饰，避免连续套用“三列卡片＋绿色短线＋浅色框”。原表最适合评审时可以保留对照结构，不必为了图片化拆卡片。

## 3. 提示词只描述规格，不代替验收

传入目标宽高比和宽高、明确品牌色值、文字逐项清单、标题与正文字重差异、对齐方式、图标限制、关系与箭头方向、背景以及不得生成的框外元素。修改现有图时说明保留项与本次唯一改动。

提示词明确写入“直角矩形为主，不使用圆角卡片和胶囊形标签”；确有已确认圆角例外时逐项限定。不得主动写入“rounded cards”“subtle rounded corners”等与默认规则相反的要求。

禁止仅写“高端商务”“中国移动风格”等笼统词。不能靠连续加入装饰性提示来解决字体、比例或业务结构问题。

## 4. 每张成图必检

1. **文字与语义**：逐字核对错字、缺字、数字、否定词、条件和对应关系；检查连线是否越过人工确认节点或产生额外业务含义。
2. **字体层级**：主标题、分组标签与正文能否区分，正文是否过粗、标题是否挤压内容。按最终放置大小检查，不能仅凭生成大图判断。
3. **配色**：按统一品牌表检查主色和对比色，必要时采样平坦区域。提示中写了HEX不代表实际像素已符合。
4. **比例与尺寸**：读取文件实际宽高，计算实际宽高比，与目标比较并记录。精确像素交付须宽高均满足；比例交付应相符，允许因整数像素产生的舍入差异，但不能将明显偏差称为匹配。例如1400×410约为3.415:1，3:1不合格。
5. **背景与完整性**：检查黑底、透明噪点、杂边、截字、重叠、缺失和图标数量；同时检查外框及内部卡片、底框、标题条、标签与流程节点的角型，不能仅因外框直角就判定合格。普遍圆角化需修正，权威模板原有固定元素保留。白底图检查实际不透明背景；透明图检查alpha和浅底显示效果。
6. **实际阅读尺寸**：以目标区域尺寸预览，检查正文是否可读，留白是否挤压有效内容，同时浏览相邻页节奏。没有PPT回填时仅声明独立图片检查，不声称PowerPoint回填验收。

比例不符不能交给用户用非等比拉伸解决。先通过允许的图像工具重排；如当前工具规则及授权允许后处理，可等比例缩放、增加合理留白或只裁无信息边缘，不能拉伸文字或裁掉内容。连续两次定向修正仍不合格时，明确具体限制及可行替代方式，不继续无目标重试，也不把当前预览当最终稿。

## 5. 回填检查（仅授权时）

优先等比例放置。检查PPT中的裁剪参数，按裁剪后的可见区域计算比例，不能仅用原图比例与对象框比例判定拉伸。检查是否重复保留原文字、遗漏侧栏、遮住页脚及发生断行变化。

通过本机PowerPoint打开并渲染修改页，检查实际显示与相邻页一致性。确认仅修改授权区域，标题、Logo、母版、页码和其他用户修改保持原样。位图内部文字不可逐项编辑，准确说明编辑范围。

## 6. 唯一最终版交付

修正版在项目交付目录使用明确版本或最终文件名；错误中间图保留在中间目录或工具默认生成目录，不混为正式候选。工具自动展示的错误预览应说明已被哪一版替代，最终回复只链接已检查的选定版本，不要求用户从多张预览辨认正确文件。

在现有项目记录中简要保存目标/实际尺寸、版本及检查范围，无需为每次小图新增繁琐文档。若仍有尺寸、色值或文字问题，标明为未完成预览，不称“符合要求”。严格区分独立图片检查、实际回填检查和全稿审查。
