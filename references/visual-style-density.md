# 正文视觉风格、页面元素与信息密度

本指南沉淀用户认可的手工正文页的视觉经验。用于后续新建、整体优化和授权正文页重构，作为默认视觉参照；当前品牌模板、用户指定风格及阅读场景优先。只读审查只报告，局部改字不扩大为全页重排。

参照的是页面元素的搭配、视觉层级、主体占比与充实程度。客户方案内容、业务目录、技术选型、参数和截图不作为通用要求；不复制参考项目原件或整页图片到技能。指南自包含，原参考文件不在本机时仍可执行。

## 1. 目标观感

正文采用正式、信息较充分的方案交流风格：浅底或白底承载内容，主题主色标识标题和重点，浅色分区与细边框组织较多信息，文字通过字号、字重、颜色和间距形成层级。主要信息占据主体，组内紧凑、组间清楚，图形与文字形成完整构图。

统一的是配色作用、标题层级、线条、标签及间距语言；各页区域数量、大小和结构随当前材料调整。允许使用分组容器、短标签、主色标题条、编号和少量图标形成丰富度，不把页面一律处理成无框散排，也不要求全部页面套相同卡片。

配色映射到当前模板主题槽位及其浅色、深色、透明度：主色用于名称、重点与边界，正文采用模板允许的深色，浅底用于分组。其他品牌沿用自身主题，不能照搬某客户的蓝色、Logo、页脚波纹或固定装饰。

## 2. 页面元素的应用

以下是可选视觉手段，不是每页必须全部出现的清单。文字容器使用原生形状承载文字，分组背景才可承载多个独立对象；母版固定几何保持原样。

| 元素 | 视觉用法 | 控制要点 |
|---|---|---|
| 浅色大分区与细外框 | 将密集内容分成可识别的区域，框内可继续开放排布 | 大区域、架构层和整体分组使用直角；按内容定高，避免多重套框和高而空的容器 |
| 主色区域标题条 | 为每个阅读区域提供醒目的入口，长度和面积服务于标题层级 | 普通矩形、轻切角或简洁箭头形可按作用选择；不是每个条目都加重色横条 |
| 主色至浅色或透明的轻渐变 | 增强区域标题、概述底块或收口带的层次，支持从重点过渡到正文 | 采用主题派生色，端点文字均有足够对比度；二维呈现，不用金属、透视、厚重立体或强光晕 |
| 短标签与小型字段框 | 让字段、类别、结果或模块名称便于扫读，多个短标签同组对齐 | 默认直角；有明确识别作用时可采用统一的轻圆角或细线圆角短标签，按第7.1节例外记录；长说明置于标签之外 |
| 编号、圆形编号点与步骤标记 | 提供定位和顺序线索，与标题和说明形成稳定层级 | 编号大小服从内容，不固定阶段数量；圆形只作编号/识别标记，不用于所有正文容器 |
| 细分隔线、短线及局部强调线 | 区分相邻区域、组织阅读节奏，避免全部依靠大背景块 | 统一线条，与业务连接器区分；装饰线无箭头，辅助斜线不成片铺设 |
| 小型二维图标 | 为区域标题或对象提供识别线索，保持页面有适量视觉变化 | 同套笔画、视觉尺寸、主题色；不为每条文字配图标，避免复杂图标抢占面积 |
| 底部结论/结果带 | 为本页收口，可用浅色底或主色底白字 | 有对应结论才使用，按内容定高；不能挤压主体或固定每页必须有 |
| 轻阴影 | 局部区域需要从背景中分离时提供微弱层次 | 同组统一、范围小；不把所有外框、标签和标题都加阴影，不依靠厚阴影制造丰富度 |
| 大幅截图与旁侧索引 | 截图作为主体，旁侧少量原生标签帮助定位 | 保持比例与清晰度，索引不挤压截图；截图边框按第9.4.4节现行母样，不继承旧稿的截图阴影 |
| 矩阵的色表头、浅色重点列与细横线 | 在密集表格中保留列识别和行阅读节奏 | 不叠加多层重边框，不以所有单元格加粗或不同颜色制造层级 |

## 3. 搭配与视觉层级

- 大区域先用浅底或细外框建立归属，区域内通过对齐、间距和小标题组织信息。标题条、标签、分隔线用于相应层级，避免多种强调同时争夺注意力。
- 顶部概述可使用浅色渐变带或直接排字；重要判断和关键词局部加粗或着主色，正文保持常规字重。概述不是额外装饰面板，位置与高度服从现行模板和实际折行。
- 单组呈现“名称＋说明”时名称突出，说明紧邻且左对齐。短标签可成组摆放，较长说明用短段落或条目展开；不能把全部内容变成同样大小的按钮或胶囊。
- 重色标题条、浅色底、细线、白底正文形成疏密与轻重变化。同一页面不让所有模块同样重，也不为追求变化加入无依据主次。
- 保留局部留白，收紧无作用的大空隙。浅底区域内不必再次放大卡片，容器高度贴合文字；组内距离通常小于组间距离。
- 同类元素跨页统一填充作用、边框、角型、字重、内边距与对齐方式；页面可以改变主体构图，不以换色、换列数替代设计。

## 4. 信息密度的视觉参照

目标是主体充实、细节可读、层级可辨。正文不因追求极简而普遍只保留巨型名称和一句短说明；已有确认文字按层级组织，合理利用正文面积。密度包含原生文字、图形标签、表格和截图内部信息，不能只数外部文字。

- **文字/图形密集页**：主要信息充分展开，名称、说明、标注分层；通过合理区域比例、紧凑组内间距、细线和浅底支持阅读。保留完整内容，先删重复文字，再调间距与同层级字号。
- **截图页**：主体面积优先给可读截图，外部说明和索引精简。截图内部已有大量字段时，不因外部字少追加卡片或段落。
- **比较或矩阵页**：共同字段对齐，正文清楚；利用色表头、重点列和细线降低扫读成本，不通过放大标签压缩单元格文字。
- **内容本来简短的页面**：保留合理留白，不用额外装饰、重复结论或虚构信息凑密度。封面、目录过渡和结束页遵循模板自身节奏。

常规正文默认14磅，密集次级说明可12磅并核验实际可读性，同层级统一；详见第5.3节。历史参考稿存在9—11磅次级文字，只作为旧稿观察，不升级为新稿字号默认值。参考页面的充实感通过区域、元素和层级组织迁移，不靠全页缩字实现。不设统一字数、区域数、图标数、填充比例或每页结论带要求。

## 5. 制作与画面检查

设计时在项目既有记录中简要说明：采用哪些元素、各自的视觉作用、区域轻重与主体面积分配、密度取舍及例外。不把原项目的业务内容登记成视觉经验，也不另建逐页文档。

重点页版式研究提示词同时描述本指南的目标观感、选用元素和充实程度；原生重构保留有效浅底、细框、轻渐变、标签和编号，不能在重构时把这些全部抽掉而丢失参考观感。二维风格允许轻渐变与轻阴影，禁止的是厚重立体表现。用户指定其他风格时按当前要求执行。

渲染后分别以缩略图和实际阅读尺寸检查：

1. 第一眼能识别主标题、主体区域和重点，元素有丰富度但没有抢走正文注意力。
2. 分区边界清楚，名称与说明有主次，组内紧凑、组间可辨，未出现高而空的容器。
3. 主体充实，必要文字和截图细节可读，无小字糊成一片、贴边、遮挡或过多强调。
4. 所选渐变、标签、编号、图标、分隔线和结论带与当前品牌协调，同类元素跨页一致；保留的圆角有具体作用。
5. 截图页和密集文字页按不同信息载体判断，不因追求同样文字量而破坏视觉节奏。
