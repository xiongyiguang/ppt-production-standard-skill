# 局部素材美化专项流程

适用于内容与结构基本确认后的PPT局部视觉增强。由用户提出或同意后启用，不作为每次制作的必经阶段。沿用主规范的模板、原生文字、主题色、箭头及PowerPoint检查要求，不另建一套视觉标准。

用户明确选择主体文字或结构整体生成位图时，改走 [imagegen-content-replacement](imagegen-content-replacement.md)。下文“关键文字保留原生”“无文字透明素材”仅适用于局部辅助插画模式，不否定已授权的主体配图替换。

## 1. 先确定值得调整的局部

以用户最新指定、可能已经手工改过标题或顺序的PPT为基线，读取当前内容及备注，查看候选页实际画面。不得从旧生成脚本重建全稿而覆盖用户修订。

按语义判断素材是否帮助识别对象、理解层次或形成视觉重点。优先考虑入口、迁移对象、文件层次、用户操作、平台关系等确有直观表达价值的局部。明细表、核实清单和职责对照通常保留原生表格，不为形式变化强行加图；空白本身不是需要填图的理由。

制作记录只需说明候选页、拟调整局部、表达作用、选用原生图形或图片、必须保留的条件。已有逐页内容表时直接补充，不重复建表。用户已授权先选后做时，可自行判断并继续，不逐张重复征求确认。

## 2. 素材选择与风格

默认不加图标；只有帮助识别对象或理解关系时才使用。用户指定数量或明确少图标、无图标时，沿用到后续同类页面；空白和版式单调不能单独成为加图标的理由。品牌颜色统一引用完整规范第8.4A节。

- 简单平台、文档、人员、容器、关系线等，优先用主题联动的原生PPT形状；确实能改善观感的概念插图再使用imagegen。生成失败或效果不合适时可以回到原生图形，不为使用工具而保留不合格图片。
- 平面二维、简洁克制，避免3D、等距立体、金属质感、复杂小图标堆叠、光晕和厚重阴影。若用户另有明确风格要求，按当次要求执行。
- 概念图片采用当前品牌主色及少量浅色、辅助色，保留视觉留白。固定色PNG是媒体例外，不宣称它可随PPT主题联动；原生图形仍使用主题槽位。
- 局部图标或插图优先真实透明背景，避免把白底矩形、棋盘格或大片背景一起插入页面。照片及确需完整背景的图片不强行透明。
- 关键文字、标题、数字、条件、方向标签留在PPT原生对象中。图中不生成伪文字，不使用整页图片代替内容页，不生成Logo、真实产品界面或事实性数据。
- 同套素材在笔画、复杂度、比例和色彩上协调，但不要求不同业务对象都套同一外形。不把项目配色推广为其他品牌的固定配色。

## 3. 生成与验收透明素材

实际需要生成或编辑位图时，先加载可用的imagegen技能并按其要求调用工具。本流程本身不要求提前调用图像生成工具。

提示词交代单个素材的语义对象、PPT中的作用、二维风格、当前品牌颜色范围、透明背景、无文字及完整留边。优先生成可独立使用的素材，避免从带复杂背景或粘连对象的大拼图里勉强裁出图标。

生成后检查主体是否准确、有无无依据的业务含义、是否完整、有无碎片和伪文字。透明验收同时检查alpha通道与实际画面：仅文件为RGBA不能证明背景透明；在白色及浅色背景上查看边缘，排除白框、棋盘格、白边、黑边和光晕。必要修图按imagegen技能及用户授权执行，不以粗暴抠除颜色损坏主体。

不合格素材重新生成、采用已有合适素材或改用原生图形。不以降低可读性、放大低清图或遮住缺陷的方式凑交付。

## 4. 放入PPT时同步调整局部版式

先确定素材与正文的关系，例如左侧辅助图配右侧问题响应、层次图旁的对象插图、流程入口旁的用户图。素材承担辅助作用，不能抢占标题和核心信息。

插入后调整邻近内容区、对齐、内边距及留白，保留标题下概述的可读字号与完整条件。不能仅把图片塞进空隙，也不能压缩表格、拉伸图形或缩小正文来腾位置。简单关系继续使用原生连接器并执行箭头规范，不把关键流程关系烘焙进图片。

各素材独立放置、等比例缩放；透明画布中的空白可影响视觉尺寸，应按主体边界判断对齐和大小。只替换确实被新素材取代的旧对象，不留下重复背景或重叠标签。

美化不改变已确认业务含义、标题、顺序及备注。若用户同时授权调整内容或顺序，检查相应备注，避免页面已变而备注仍讲旧内容。仅美化时不要顺带重写全稿备注。

## 5. 对照检查与交付

从最新输入另存版本，记录输入文件哈希、实际修改页和素材来源。未改页面及受保护模板部件保持不变；转换方式导致字节变化时，应核对内容、对象和几何，不声称字节未变。

按主规范实际用PowerPoint打开并渲染全部修改页。逐页检查图片透明边缘、比例、清晰度、文字遮挡、对象对齐及留白，并浏览相邻页面判断全稿节奏。发现问题后修正并重新渲染受影响页。结构审计通过不能替代视觉检查；只检查修改页时不能称全稿逐页验收。

交付说明哪些页进行了局部增强、哪些内容保持不变，以及实际检查范围。生成素材是独立位图、文字和结构是原生对象时，应准确说明，不称全元素可编辑。不自动把客户PPT、截图或专属品牌素材复制到全局技能资产库。

## 6. 已验证的设计经验

以下是数据迁移汇报的抽象案例，不是固定页码或必须复用的页面模板：

| 内容特点 | 有效的局部处理 | 不应做的处理 |
|---|---|---|
| 迁移背景与目标 | 迁移概念插图辅助问题—响应对照 | 整页大图代替具体安排 |
| 文件本体、目录、访问三个层次 | 保留原生分层文字，辅以简洁透明文件素材 | 把功能误画成在线云文档编辑产品 |
| 用户自助迁移 | 用户入口小素材配合原生步骤流程 | 将全部步骤和文字生成为一张图片 |
| 规划资料准备 | 资料核查素材辅助分组清单 | 给每个字段都配图标，挤压信息 |
| 新旧平台并行与接续 | 原生平台轮廓与主题联动连接器 | 保留带光晕、厚阴影的生成平台图 |

案例用于帮助判断，不能照搬客户信息、页码、颜色或布局。后续是否需要素材仍由当前页面内容决定。
