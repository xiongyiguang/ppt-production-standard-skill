# PPT Production Standard

面向 PowerPoint 制作、改版与审查的规范技能：保留权威品牌模板，根据真实内容组织页面，使用可编辑对象，并通过结构、编辑性与实际渲染检查确认交付质量。

本仓库提供制作规范与辅助检查工具，需配合支持 PPTX 的制作工具使用。技能入口为 [SKILL.md](SKILL.md)。

## 能做什么

- **新建演示文稿**：从明确的品牌模板出发，先形成页面判断，再根据内容关系构图。
- **改版与局部修订**：在指定范围内修改，保护母版、主题、固定装饰和原有对象。
- **截图与旧页重建**：区分需要原生重建的文字和结构，以及应保留的真实图片、界面截图。
- **质量审查**：检查模板一致性、主题色、文字格式、对象编辑性、连接器与渲染结果。
- **关系表达**：提供12类结构图与数据图方法，帮助把业务关系转化为具体画法。

它不单独承担完整售前内容策划，也不用于 HTML 演示制作。仅做审查时，不自动修改文件。

## 如何使用

将仓库完整目录放入支持 `SKILL.md` 的助手技能目录，并命名为 `ppt-production-standard`。例如本机 Codex 常用目录为 `~/.codex/skills/ppt-production-standard/`；已有同名技能时，先比较版本再更新。

在任务中明确技能、材料、品牌和修改范围。例如：

> 使用 $ppt-production-standard，依据我提供的品牌模板和方案材料制作演示文稿。保留母版与固定品牌元素，内容图采用可编辑对象，完成后报告结构、编辑性和视觉检查结果。

> 使用 $ppt-production-standard，只审查这份 PPT 的文字、对象和版面问题，不修改文件。

按任务提供原始材料、权威模板、受众、页数或演讲时长等已知条件。客户事实、数据和承诺以材料为准；没有依据的内容不能为填满页面而补造。

## 12 类关系表达方法

详见 [关系表达方法指南](references/relationship-patterns.md)。每类包含必要输入、结构草图、构图方式、变化条件、可编辑实现和语义验收点。

| 方法 | 主要用途 |
|---|---|
| 战略房屋 | 解释目标、支柱、举措与共同基础 |
| 2×2 矩阵 | 按两个维度定位对象；BCG作为专用变体 |
| 问题树 | 分解问题、原因、假设或解决路径 |
| 价值链 | 展示价值活动与介入位置 |
| 流程图 | 表达步骤、条件、交接与异常回流 |
| 桥图／瀑布图 | 解释从起点到终点的增减贡献 |
| Mekko 市场份额图 | 同时表达市场规模与内部份额 |
| 甘特／路线图 | 对齐任务、时间、里程碑与交付物 |
| 多支柱网格 | 组织多个方向下的行动与成果 |
| 散点／气泡图 | 比较数值维度及第三维规模 |
| 漏斗图 | 表达同口径对象的逐级筛选与转化 |
| 组织／利益相关方地图 | 分别表达汇报层级和协作网络 |

这些方法按内容需要选用，不是固定样页，也不要求每页套用。节点数、方向和比例随真实关系调整，不为凑版式补字、补数据或删减条件。

## 核心制作原则

1. **模板优先**：保留权威模板的母版、版式、主题及固定品牌元素。
2. **内容驱动**：先明确本页判断、证据、主要关系和必要条件，再设计页面。
3. **保持可编辑**：优先原生文字、形状、表格、图表和连接器；容器文字直接写入形状。
4. **品牌联动**：适用对象使用主题色引用，不用外观相同的固定色值冒充主题联动。
5. **清晰可读**：正文默认14磅，最小12磅；内容过多时重组或拆页，不靠无限缩小文字解决。
6. **分别验收**：结构检查通过不等于编辑体验或视觉验收通过，未完成的检查明确标注。

完整规则以 [制作规范](references/ppt-production-standard.md) 和当前任务的明确要求为准。

## 环境与验证边界

- Python辅助脚本按实际工具需要配置 `python-pptx`、`lxml`、Pillow等依赖；具体参数先查看脚本帮助或对应参考文档。
- macOS 下使用可用的演示文稿制作工具；实际应用检查可在 Mac PowerPoint 或 Windows 虚拟机内的 PowerPoint 完成，以实际安装环境为准。只有虚拟机内安装 Office 时，在虚拟机内执行 COM 检查。
- `render_pptx_powerpoint.ps1`、`measure_text_layout.ps1` 依赖 Windows PowerPoint COM，不能直接在 Mac 上执行；安装 PowerShell 也不会提供 COM 能力。
- 使用前检查字体是否可用。第三方预览可作辅助证据，不能直接等同于 PowerPoint 实际显示结果。
- 方法文档及静态检查不代表所有画法已通过真实业务、编辑性和视觉验收；每次交付仍须按任务验证。

## 素材与发布范围

品牌模板和素材应在已有授权范围内使用；仓库公开不等于获得品牌或第三方素材的使用授权。客户原文、客户样稿、凭据、缓存和临时渲染结果不应作为通用技能资源提交。

关系表达方法的分类参考来源及改写边界见对应指南末尾。本仓库不依赖 WorkBuddy 的 `slidep` 制作工具。
